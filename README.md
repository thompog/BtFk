# BtFk
BtFk is a simple 2 man project that does simple things with GUI thats it for now


# How to install
Step 1:

  install Python 3.14 and up 
  we recommend using: https://www.python.org/ftp/python/3.14.6/python-3.14.6-amd64.exe
  
  run installer

Step 2:

  Press Win + r
  
  Type: cmd
  
  Press enter
  
  Type: python -m pip install requests
  
  Press enter

Step 3:

  install BtFk (https://github.com/thompog/BtFk/releases/tag/verions)
  
  run BtFk (click two times on the program)

if step 3 does not work try with cmd

RUN VIA CMD:

  Press Win + r
  
  Type: cmd
  
  Press enter
  
  cd in to local dir via cd /d 
  
  Type: python BtFk.py

if it still does not work then a module that it uses is not installed so just install what the cmd windows says its missing
